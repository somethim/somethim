Overview

A fully documented simulator for an autonomous cleaning robot. The robot visits every reachable room, detects and cleans multiple dirt types, replans around obstacles that appear mid-run, and returns to its dock before the battery model runs out. Everything runs at 10× real time with a fixed-step control loop.

Architecture

The simulator is built around five independently clocked sensor tasks — wheel odometry, IMU, LiDAR, cliff sensor, and bump ring — each running in its own Tokio task on its own sample rate. Their measurements flow into a fusion task that applies them in timestamp order:

  • Bounded replay buffer — measurements are staged and sorted so late arrivals never corrupt the filter.
  • Innovation-gated corrections — LiDAR-to-wall corrections pass a chi-squared gate before touching the estimate.
  • Fixed-step control — planning and motion run on a deterministic tick, independent of sensor timing.
fn drain_ready(&mut self, now: SimTime) -> Vec<Measurement> {
    let horizon = now - REPLAY_WINDOW;
    self.staged.split_off_ready(horizon)  // sorted by timestamp
}

Results

The filter holds pose error under 3 cm across a full apartment run while rejecting roughly 2% of LiDAR corrections as outliers — a rejection rate that doubles as the system's best health metric. The whole run is reproducible: the same seed produces the same dirt layout, the same obstacle schedule, and the same trajectory.

Running it

# headless run with the default apartment
cargo run --release -- --map apartment --speed 10

# with the visualizer
cargo run --release --features viz
