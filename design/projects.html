Cave Robot

Autonomous cave-navigation drone

Six-crate Rust workspace integrating procedural 3D voxel caves, EKF localization, SLAM, ROS 2, and Gazebo. Clearance-weighted A* plans outbound on the known map while LiDAR builds an occupancy map for the return path.

Robotics · Simulation

Roomba

Autonomous cleaning robot

A documented 10× real-time simulator that visits reachable rooms, cleans multiple dirt types, replans around obstacles, and returns to dock. Five independently clocked Tokio sensor tasks feed timestamp-ordered fusion with innovation-gated EKF corrections.

Rust Tokio EKF Sensor fusion

Research · B.Sc. Thesis

Event-Aware Traffic Prediction

A negative result, tested reproducibly

Evaluated 5.68 million sensor-time rows and 164 verified concerts through 540 controlled Random Forest and XGBoost fits. Event metadata degraded real-data predictions; controlled synthetic experiments recovered the injected effect, validating the mechanism without overstating the outcome.

Python XGBoost Random Forest
