# Monorepo → Single Next.js App Migration

Flatten `apps/web/` to the project root and inline all `packages/*` as local modules under `src/`. Result: a plain Next.js project with no Turbo, no workspace deps, no package builds.

---

## Phase 1 — Move `apps/web/` to root

Move from `apps/web/` directly to root (replacing monorepo root files):

- `src/` → `src/`
- `public/` → `public/`
- `declarations/` → `declarations/`
- `next.config.ts` → `next.config.ts`
- `postcss.config.mjs` → `postcss.config.mjs`
- `next-env.d.ts` → `next-env.d.ts`
- `instrumentation-client.ts` → `instrumentation-client.ts`
- `.env.local` → `.env.local`

---

## Phase 2 — Inline packages as local modules

| Package | Source | Destination |
|---|---|---|
| `@zenncore/web` | `packages/web/src/` | `src/ui/` |
| `@zenncore/utils` | `packages/shared/utils/src/` | `src/lib/utils/` |
| `@zenncore/icons` | `packages/shared/icons/src/` | `src/lib/icons/` |
| `@zenncore/inferred-form` | `packages/shared/inferred-form/src/` | `src/lib/inferred-form/` |
| `@zenncore/phone` | `packages/shared/phone/src/` | `src/lib/phone/` |
| `@zenncore/data-table` | `packages/shared/data-table/src/` | `src/lib/data-table/` |

**Skip `@zenncore/editor`** — declared as a dep but never imported anywhere in the app source.  
**Skip `@zenncore/config`** — pure build/TS config; content is inlined in later steps.

## Phase 3 — Rewrite cross-package imports

| Old | New |
|---|---|

| `@zenncore/web/` | `@/ui/` |
| `@zenncore/utils/hooks` | `@/lib/utils/hooks` |
| `@zenncore/utils/types` | `@/lib/utils/types` |
| `@zenncore/utils` | `@/lib/utils` |
| `@zenncore/icons` | `@/lib/icons` |

| `@zenncore/phone` | `@/lib/phone` |
| `@zenncore/data-table` | `@/lib/data-table` |

Applies in: app source (`src/app/`, `src/server/`), inlined UI (`src/ui/`), and inlined utility packages (`src/lib/inferred-form/`, `src/lib/phone/`, `src/lib/data-table/`).

## Phase 6 — New root `package.json`

Start from `apps/web/package.json`. Remove all `@zenncore/*` entries. Add the npm packages they wrapped:

- `@base-ui/react` (dialog, sheet, other UI primitives)
- `@base-ui/utils` (re-exported by utils)
- `class-variance-authority` (cva helper)
- `clsx` + `tailwind-merge` (cn helper)
- `es-toolkit` (re-exported utilities)
- `type-fest` (type utilities)
- `@tanstack/react-table` (data-table)
- `react-hook-form` (was catalog dep)

Update scripts to remove turbo:
```json
"scripts": {
  "dev": "next dev",
  "build": "next build",
  "start": "next start",
  "lint": "biome check --fix --unsafe .",
  "typecheck": "tsc --noEmit"
}
```

Remove `"workspaces"`, `"engines"`, `turbo`, `@turbo/gen` devDeps.
